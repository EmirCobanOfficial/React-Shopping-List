## 📖 About

A small front-end project for practicing React state management — lifting state up,
controlled forms, and derived (filtered) lists. State is kept in memory (no backend).

> The starter items are in Turkish and are for demonstration purposes.

## ✨ Features

- ➕ **Add items** to the list
- ✅ **Toggle complete** with a checkbox (adds a strikethrough)
- 🔎 **Filter** by All / Incomplete / Completed
- 🗑️ **Delete** individual items or **clear** the whole list

## 🛠️ Tech Stack

- [React 19](https://react.dev/)
- [Vite 6](https://vitejs.dev/)
- [Bootstrap 5](https://getbootstrap.com/) + Bootstrap Icons

## 🚀 Getting Started

```bash
git clone https://github.com/EmirCobanOfficial/React-Shopping-List.git
cd React-Shopping-List
npm install
npm run dev
```

The app runs at **http://localhost:5173**.

### Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
